# Header artwork

`sierra_romeo.png` is the user-supplied Sierra Romeo illustration, included at
the project owner's explicit request as the README header. It is not extracted
from the retail disc. No third-party reuse license is asserted for this artwork.

`sr_installer_icon.ico` and its PNG source were supplied by the project owner
for the installer on September 18, 2026. Both are preserved byte-for-byte.
The ICO is embedded in the setup EXE and used by its window/taskbar. These
artwork files are excluded from the GPL grant on original project code; no
separate reuse license is asserted.
