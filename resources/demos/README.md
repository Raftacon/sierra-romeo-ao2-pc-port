# Sierra Romeo demonstration captures

Captured from the local Windows development build on September 18, 2026, using
an isolated copy of the player profile. The original profile was checked unchanged.
These are window-only captures, with the window frame removed; no desktop or
other applications are included.

- **campaign-readability.gif:** edited montage of training dialogue with the
  subtitle backing, a vault and movement through the training area, and the
  enlarged checkpoint table. The later table is opened through the diagnostic
  preview command using the real in-game widget and current stats. This is a UI
  demonstration, not a recording of a newly completed combat checkpoint.
- **hold-b-to-skip.gif:** the retail AGGRO tutorial video, replayed with the
  engine's `MOVIETEST AGGRO` command. Shows the prompt, an incomplete hold, then
  a completed hold and return to gameplay. The runtime confirmed a successful
  original movie-stop request. This does not demonstrate skipping every
  in-engine cinematic.
- **pc-coop-connections.gif:** cropped montage of the native Private and Public
  co-op connection panels: join mode, LAN search, host address/invitation rows
  and the public room browser. No public directory was configured for this
  capture. This demonstrates UI, not a connection between separate computers.

GIFs use reduced color palettes and 6–8 captured frames per second for web
delivery. Their frame cadence is not a game-performance benchmark. The capture
tool records real sample times before encoding. Edits shorten the demonstration;
they do not synthesize game UI or add feature overlays.

The captures depict the original copyrighted game. They are included as feature
demonstrations at the project owner's request, not as reusable game assets, and
are excluded from the GPL license on original project code.
